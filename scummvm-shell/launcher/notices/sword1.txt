Broken Sword Read Me====================Broken Sword by Revolution SoftwareApple Macintosh conversion by Digital AmusementPublished by Virgin Interactive EntertainmentInstalling=========You must install the game to your hard disc in order to play. To do this copy the "Install Broken Sword" program onto your desktop, by holding down the ALT key whilst holding the left mouse button on the icon and dragging it onto your desktop, before releasing the left mouse button. Execute the installer by double clicking on it.Select a folder in which to install the game into. To create a new folder for Broken Sword click the mouse pointer on New Folder and rename it Broken Sword, then click on create. The installation program will then automatically take you into this new folder, so using the mouse pointer click on Select this folder and the game will install onto your machine.30 megabytes of hard drive space is required to install Broken Sword demo.Extensions----------Broken Sword requires a substantial amount of memory to run (10 megabytes). It may be necessary to turn off some system extensions and or control panels in order to run the game. Broken Sword requires the following extensions are enabled:Apple CD-ROMSound Manager {3.1 or above}Quick TimeQuick Time Power PlugTo activate these extensions follow these steps from the desktop:Click on the Apple logo in the top left corner and choose "Control Panel".Select "Extensions Manager".Highlight the Extensions listed above.Select "Save Set" and enter an appropriate name for later use.Re-boot for these changes to take effect.If your system does not have the required extensions then they may be copied from the extensions folder into your extensions folder, which is located inside the system folder on your startup disc.If you are having trouble getting Broken Sword to run, then first try using only those extensions described above.The latest version of Quick Time (2.5) and Sound Manager (3.2) are located on within the Extensions folder.To install Quick Time go into its folder and run the installation program from the CD.To install Sound Manager drag both files from the Sound Manager folder on the CD onto the System Folder icon located in the root of your Startup Disk.NoteSome applications or extensions may still be displayed whilst Broken Sword is running, the Control Strip for example. Although these will not affect the operation of the game they may spoil the look. Turn them off in the extensions manager.It is not recommended that other applications software is left running in the background whilst Broken Sword is playing, as the game makes heavy use of the Machintosh's resources. Close down any running applications before commencing playing.Virtual Memory--------------Broken Sword is fully compatable with Virtual Memory. It is not recommended that too much Virtual Memory is used as this may slow down disc access.Playing Broken Sword-------------------Open the Broken Sword folder on your hard drive.Double click on the PPC icon to start.In Game Controls---------------Mouse Button - Action (use, speak)Apple Key - ExamineEscape, F5 - Control PanelSpace - Pause, UnpauseScreen Resolution----------------Broken Sword will only use the full screen if your desktop is set to 640x480 resolution. A higher resolution will result in the game being run within a smaller window.Customer Service----------------If you require gameplay hints then please call our Broken SwordHint-Line on 0891 333528All calls will cost 50p per minute at all times and these charges are correct as of March 1997.
