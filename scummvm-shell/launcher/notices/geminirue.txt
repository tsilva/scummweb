CONTROLS:
========================================
GAMEPLAY
--------------------
Left Click:      Walk / Perform Action (in Verb Interface)
Right Click:    Bring up Verb Interface / Look at Inventory Item (in Verb Interface)
Double-Click:  Redo Last Action


ACTION
--------------------
W:	Switch Target
A:	Return to Cover / Go out of Cover (Top Side)
S:	Return to cover from either side (Not always applicable)
D:	Go out of Cover (Bottom Side)
R:	Reload
SPACE:	Fire
CTRL:	Breathe In
ESCAPE:	Cancel Action (Not always applicable)


BOX
--------------------
W:	Get on Box
A:	Move Box Left
D:	Move Box Right
S:	Cancel Box / Get off Box

MENU
--------------------
F1: 	Help
F5:	Save
F7:	Load
F9:	Restart
F10:	Load Autosave
ESCAPE:	Menu / Skip to Walk Destination (Only works in certain scenes)
Ctrl-Q: 	Quit Game


You can die in the game, but it will AUTOSAVE before most death sequences.
In addition, you can save the game manually, as well with F5.

The difficulty of the COMBAT may be changed in the OPTIONS menu between MEDIUM and EASY.

Commentary mode is disabled in the DEMO version.
