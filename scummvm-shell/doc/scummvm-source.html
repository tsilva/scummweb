ScummWEB

ScummVM source and licenses

ScummWEB distributes a modified browser build of ScummVM v2026.4.0 dated 2026-11-07. The runtime is licensed under the GNU General Public License, version 3 or later.

Download both parts for the corresponding source for this browser build.

  • Download the pinned upstream ScummVM source
  • Download ScummWEB’s patches, build scripts and library sources

The ScummWEB archive includes instructions for applying the patches and rebuilding the runtime without game files. It also lists SHA-256 checksums for the browser binaries. The Emscripten 4.0.10 sources include the runtime and port build recipes. The JPEG implementation is based in part on the work of the Independent JPEG Group.
